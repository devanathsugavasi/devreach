# Getting Help

- **Installation problems or a skill behaving badly:** open a [bug report](https://github.com/devanathsugavasi/devreach/issues/new?template=bug_report.yml). Include your OS, Claude Code version (`claude --version`), the skill name, and the prompt you used.
- **Idea for a new skill:** open a [skill request](https://github.com/devanathsugavasi/devreach/issues/new?template=skill_request.yml).
- **Want to contribute but not sure where to start:** read [CONTRIBUTING.md](CONTRIBUTING.md) and look for issues labeled `good first issue`.
- **Security issue:** follow [SECURITY.md](SECURITY.md). Do not post it publicly.

DevReach is maintained by volunteers. There is no guaranteed response time, but every well-described issue will be read.
