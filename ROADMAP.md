# Roadmap

This roadmap is a direction, not a promise. Priorities change based on what users report.

## v0.1 — Initial collection (current)

- [x] 12 skills, 4 marked core, 8 experimental
- [x] Validator, link checker, CI
- [x] Manual evaluation rubric and cases
- [ ] Manual evaluation run recorded for each core skill
- [ ] Short demo recording

## v0.2 — Earn the "core" label honestly

- [ ] Run every evaluation case in `evals/cases/` against each core skill and publish scores
- [ ] Collect feedback from at least 10 external testers
- [ ] Promote experimental skills that score ≥ 4 on every rubric dimension
- [ ] Merge or remove skills that overlap in practice

## v0.3 — Easier installation

- [ ] Install script that copies selected skills (no dependencies)
- [ ] Evaluate packaging as a Claude Code plugin
- [ ] Document behavior with other agents that read `SKILL.md` — only after testing them

## Later / ideas

- Voice profile reference: let users save writing samples that every skill reads
- Conference talk proposal skill
- Changelog-to-release-notes skill
- Lightweight automated checks for banned clichés and unsupported numbers in outputs

Have an idea? Open a [skill request](https://github.com/devanathsugavasi/devreach/issues/new?template=skill_request.yml).
