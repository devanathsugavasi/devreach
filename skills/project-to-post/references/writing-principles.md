# Writing Principles for Developer Posts

Load this file when drafting hooks or reviewing a draft.

## Hooks

A hook is the first one or two lines, before the "see more" cut (about 140 characters on LinkedIn mobile).

Good hooks state something specific:

- "Our first version took 11 seconds to answer a question. The fix wasn't a bigger model."
- "I deleted 40% of the code in my side project last week and it got faster."
- "We built a sign-language translator in 36 hours. The hardest part was the dataset, not the model."

Weak hooks are vague or ask for attention:

- "I'm excited to share something I've been working on!"
- "Have you ever wondered how AI works?"
- "Big news! 🚀🚀🚀"

## Banned phrases

Rewrite any sentence containing these. They signal generic AI writing and readers skim past them.

- thrilled / excited / humbled to announce
- game-changer, revolutionary, cutting-edge, next-level
- in today's fast-paced world, in the ever-evolving landscape
- leverage (as a verb meaning "use"), synergy, unlock the power of
- delve, tapestry, testament to
- "Let that sink in." / "Read that again."
- "Agree?" as a closing line
- more than two emoji in a post; any emoji used as a bullet

## Structure that works

1. **Hook** — specific claim or tension.
2. **Context** — what the project is, in one sentence a non-specialist understands.
3. **The story** — one decision, constraint, or surprise. Not a feature list.
4. **Concrete detail** — a library, a number the user supplied, a design choice, a trade-off.
5. **Reflection** — what you'd do differently, or what's next.
6. **Specific ask** — "If you've deployed Whisper on CPU, how did you handle latency?" beats "Thoughts?"

## Voice

- Write in first person, active voice.
- Short paragraphs (1–3 lines). Line breaks are fine; one-word lines are not.
- Match the user's samples if provided: sentence length, formality, use of humor.
- Credit teammates with what they actually did, not just tags.

## Honesty rules

- "We built" only if the user built it. "I contributed X" if it was a team.
- "Users" means real people who used it. Demo judges are not users.
- Hackathon placement must be stated exactly ("2nd place in the AI track", not "won").
- If a number is approximate, say so ("about 200 people tried it").
